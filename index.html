Core Architecture

Engineered for Sovereignty

Every layer of UnityIDE is built around one principle: your source code never leaves your control. Not even we can read it.

Isolated Contexts

Every project runs in a hardware-isolated eBPF sandbox. No shared memory, no cross-project leakage. Each context is cryptographically attested at boot.

Native Performance

Zero-Knowledge

AES-256-GCM per-file encryption with keys derived from your passphrase using Argon2id. Servers store only ciphertext — mathematically incapable of reading your code.

Security Layer

The Vault Architecture

Three hardened layers between your code and the outside world. Built on proven cryptographic primitives, not security theater.

  • Per-File Encryption

    Every file gets a unique AES-256-GCM key. Compromise one key and only that file is exposed — never your entire workspace.

  • Ephemeral Environments

    Build and run environments are spun up fresh for every session and destroyed completely on exit. No persistent footprint.

  • Forensic Audit Logs

    Immutable, tamper-evident logs of every file access, build event, and network call. Cryptographically signed by the runtime.
